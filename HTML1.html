HTML, CSS and JavaScript

In this lab, I learned hwo to separate my HTML, CSS and JavaScript into their own individual files and link them together. I also learned how to reference HTML elements by their class name in both CSS and JavaScript, how to build a navigation bar, and how to implement a darkmode toggle that saves the user preference across pages.

Section 1

Pre Lab- Pulling the Repository

Before starting this lab I created a new folder in my local Workspace. I then opened the terminal inside it and pulled my GitHub repository down using the command line so I had an up to date local copy of all my files to work from. This is important because the workspace files are only available for 48 hours so pulling from GitHub ensures I always have the latest version of my work.

Section 1- continued

Creating CSS and JavaScript Files

In Visual Studio Code I clicked File then New Text File to create a new empty file. I then clicked File then Save As and named it styles.css saving it in the same folder as my index.html file. I repeated this exact process again to create a second file named script.js. These two files are where all my styling and JavaScript code will be written separately from the HTML itself. Keeping them in separate files makes the code much easier to read, manage and update.

Section 1- continued

Linking CSS and JavaScript to HTML

I then needed to connect my CSS and JavaScript files to my HTML so they could work together. To do this I added a link tag inside the head section of my HTML pointing to styles.css. I also added a script tag at the very bottom of the body section pointing to script.js. Without these two lines the HTML would not know that the CSS and JavaScript files exist and none of the styling or functionality would work.

Section 2

CSS Styling by Tag

I opened my styles.css file and added CSS rules that target HTML elements by their tag name. For example adding a rule for h1 changes every h1 heading on the page. This is useful for applying consistent styling across all elements of the same type without having to style them individually. I could see the changes immediately when I refreshed the website in the browser.

Section 2

JavaScript Accessing Classes

I opened my script.js file and used document.querySelector to access my HTML elements by their class names. I stored them in variables called myName and myDescription. I then used console.log to print them to the developer console in the browser. I pressed F12 to open the developer tools and clicked Console to see the results. The console showed both elements which confirmed that JavaScript was correctly picking up the classes from the page.

Section 3

Navbar

I needed a way to navigate between the different lab pages so I first created a simple ordered list of links in my index.html. I then converted this into a proper navigation bar using HTML and CSS. The navbar sits fixed at the top of every page and contains links to each lab. I styled it with a teal background colour and added hover effects so the links highlight when the mouse moves over them. The Home button has a highlighted background to show the current active page.

Section 4

Dark Mode

The final task was to implement a dark mode toggle on my website. I added a button to the navbar in my HTML. In my CSS I created a dark-mode class on the body element with different background colour variables so when the class is applied the whole page changes colour. In my JavaScript I added an event listener to the button so when it is clicked it toggles the dark-mode class on and off. I also used localStorage to save the user preference so the dark mode stays consistent when moving between pages. I added a CSS transition so the colour change fades smoothly instead of switching instantly.

Reflection

What I Learned

In this lab I learned how to structure a website properly by separating HTML, CSS and JavaScript into their own individual files and linking them together. I also learned how to reference HTML elements by their class name in both CSS and JavaScript which is a fundamental technique used in all modern web development. In industry keeping HTML, CSS and JavaScript in separate files is considered best practice. It makes code much easier to read, maintain and work on as a team. Features like dark mode are also used on most modern professional websites and understanding how JavaScript can interact with CSS classes to dynamically change the appearance of a page is a core skill for any front end developer.
