In this lab I explored key memory management concepts including virtual memory, paging, Translation Lookaside Buffers and memory interfacing. Task-1

Virtual Memory and paging

Virtual memory divides main memory into fixed size blocks called pages. A virtual address consists of a Virtual Page Number and an offset. Given a 4 bit VPN and 8 bit offset the number of virtual pages is 2 to the power of 4 which equals 16 pages and bytes per page is 2 to the power of 8 which equals 256 bytes. For virtual address 0x2C8 the VPN is 2 and offset is 0xC8. Looking up VPN 2 in the page map gives PPN equal to 4 so the physical address is 0x4C8.

Page Frames

The bottom 32K of main memory is divided into eight page frames of 4KB each. Each page frame covers a range of 4096 bytes. The missing values are calculated by adding 4095 to the start address of each frame since addresses begin at 0. The answers are A equals 32767, B equals 24575, C equals 16383 and D equals 4095.

Task 3

Page Table and 32-bit virtual Address

For the 32 bit virtual address the first 20 bits represent the page number and the last 12 bits represent the offset. The virtual page referenced is Page 1. Looking up Page 1 in the page table gives a page frame value of 001 in binary which is 1 in decimal. The physical address is constructed by combining the page frame with the offset giving 0x117F.

Task 4

TLB Simulation Code

A Translation Lookaside Buffer is a small fast cache that stores recent virtual to physical address translations. I implemented a TLB simulation in C# with a capacity of 4 entries. The simulation processes a sequence of virtual page number accesses and tracks hits and misses. A TLB hit occurs when the required VPN is already in the TLB. A TLB miss occurs when it is not found and requires a slower page table lookup instead.

Reflection

What I Learned

In this lab I learned how operating systems manage memory using virtual memory and paging. The MMU maps virtual addresses to physical addresses using a page table and the TLB speeds this up by caching recent translations. Page faults occur when a required page is not in physical memory and must be loaded from disk. In industry memory management is critical for system performance and stability. Virtual memory allows programs to use more memory than is physically available by using disk space as an extension of RAM. The TLB is essential for performance as without it every memory access would require a page table lookup which would slow the system significantly. Understanding these concepts helps developers write memory efficient programs and understand why memory management affects overall system performance.
