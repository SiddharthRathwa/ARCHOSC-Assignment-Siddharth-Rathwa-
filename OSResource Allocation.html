OS Resource Allocation

In this lab I explored how resources are allocated on a computer system and how to analyse safe and unsafe states using the Banker's Algorithm. The Banker's Algorithm is a deadlock avoidance algorithm that determines whether a system is in a safe state by finding a safe sequence of process execution. I manually analysed three different resource configurations and implemented the Banker's Algorithm in C# to automatically determine system safety and output the safe sequence.

Task 1

Manual Analysis

The Banker's Algorithm determines if a system is in a safe state by finding a safe sequence which is an order in which all processes can complete without causing deadlock. With available resources R1=10, R2=5, R3=7 and the allocation equal to the maximum demand for all processes the need is 0 for every process. This means all processes can complete immediately and release their resources back to the available pool. The system is in a safe state. Safe Sequence: P1 -> P2 -> P3 -> P4 -> P5.

Increasing Resources

Resource R1 was increased from 10 to 12. With more R1 available the system has greater flexibility in choosing which processes to run first. After recalculating the need matrix and applying the Banker's Algorithm the system remains in a safe state. The extra 2 units of R1 allow more processes to satisfy their needs earlier in the execution sequence reducing waiting time and improving throughput. Safe Sequence: P4 -> P2 -> P5 -> P1 -> P3.

Task 4

Banker's Algorithm code

I implemented the Banker's Algorithm in C# that takes user input for the number of processes and resource types. The program accepts the allocation matrix, maximum demand matrix and available resources as inputs. It then calculates the need matrix by subtracting the allocation from the maximum demand for each process. The safety algorithm checks each process to see if its need can be satisfied by the current available resources. If it can the process runs, completes and releases its resources back to the available pool.

Reflection

What I Learned

In this lab I learned how operating systems use the Banker's Algorithm to avoid deadlock by carefully managing resource allocation. A deadlock occurs when processes are waiting for resources held by each other and no process can continue. The Banker's Algorithm prevents this by only granting resource requests if the resulting state is still safe. In industry resource management is critical for system reliability. Deadlocks can cause entire systems to freeze requiring a restart which can be catastrophic in real time systems such as aircraft control, medical equipment or financial trading platforms. The Banker's Algorithm shows how careful planning and analysis of resource allocation can prevent these situations. Understanding deadlock avoidance helps developers design more reliable and robust software systems that can handle resource contention gracefully without crashing or freezing.
